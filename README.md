# Wii-EMT
Wii EMT scans for devices on the hosts network and can disable their WiFi. 
# HOW TO USE:

Wii EMT also runs on dependencies to fully execute. First, open CMD, then type command: pip install scapy paramiko
Upon installing, execute the file, and it will scan for all devices on the user's network, also providing each device's respective IP address as well. The user can then click a user and disable their WiFi, which the targeted device can still turn on.
